# Бортовой журнал

Проект роста и копилка школьных разборов. 6 класс.

Открыть: **https://ЛОГИН.github.io/domashka/** — подставьте свой логин GitHub после публикации.

## Что внутри

Одна самодостаточная страница `index.html`. Ни серверов, ни библиотек, ни внешних запросов, кроме шрифтов Google Fonts.

Два режима, переключатель в шапке:

- **Капитан** — то, чем пользуется ребёнок: Сегодня, Календарь, Уроки, Тесты, Вызовы, ГТО
- **Штурман** — плюс Курс (философия и правила проекта), Печать и Прогресс

### Вкладки

| Вкладка | Что делает |
|---|---|
| **Сегодня** | Вахта на текущий день, план из календаря, взятые вызовы, серия, и блок «Пора повторить» |
| **Календарь** | Переходы по месяцам с задачей на каждый день; переключение вперёд-назад |
| **Уроки** | Разборы домашних заданий: картотека с поиском, фильтр по полугодиям, темы по предметам |
| **Тесты** | По теме, по предмету, большой тест и работа над ошибками. Перед стартом правила и шпаргалка |
| **Вызовы** | Банк из 25 карточек по пяти румбам |
| **ГТО** | Нормативы III и IV ступени, автоматический подсчёт знака, микроцикл тренировок |
| **Курс** | Концепция проекта, звания, правила перехода, список учебников |
| **Печать** | Четыре листа на бумагу: плакат, чек-лист недели, карточки на разрез, договор |
| **Прогресс** | Выгрузка и загрузка прогресса файлом, статистика, результаты по темам |

### Как считаются узлы

- пункт вахты — 1 узел, максимум 5 в день
- сданный вызов — 5 или 8
- тест на 80% и выше — 5 узлов, один раз за тему; заодно закрывается пункт «Ум» за сегодня

## Сохранение прогресса

Отметки хранятся в браузере устройства (`localStorage`) и между устройствами сами не переносятся. Во вкладке **Прогресс** есть кнопки **«Сохранить в файл»** и **«Загрузить из файла»** — это и резервная копия, и способ перенести всё на планшет.

Загрузка заменяет весь текущий прогресс на устройстве, поэтому переносите в одну сторону: с того устройства, где отмечали, на то, где нет.

У каждого разбора в картотеке стоит метка **сверено с учебником** или **требует проверки** — чтобы было видно, чему можно доверять без оговорок.

## Как обновить страницу

1. Открыть репозиторий на github.com
2. **Add file → Upload files** → перетащить новый `index.html` поверх старого
3. **Commit changes**

Через минуту-полторы страница обновится у всех. Прогресс при этом не теряется: он лежит в браузере, а не в файле.

## Приватность

Репозиторий публичный — это условие бесплатных GitHub Pages. В файле нет имён, фамилий, оценок, расписания и любых персональных данных: только разборы школьных тем и нормативы ГТО. Страница закрыта от поисковых роботов через `<meta name="robots" content="noindex, nofollow">`, но по прямой ссылке доступна любому. **Не добавляйте сюда персональные данные ребёнка.**
