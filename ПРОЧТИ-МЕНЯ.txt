КАК ОПУБЛИКОВАТЬ ЭТУ ПАПКУ НА GITHUB PAGES
==========================================

Займёт минут пять. Файлы в этой папке трогать и переименовывать не нужно.


ШАГ 1. Аккаунт
--------------
Если аккаунта нет — зарегистрируйтесь на github.com
(кнопка Sign up, нужна почта и пароль).


ШАГ 2. Создать репозиторий
--------------------------
1. Нажмите "+" в правом верхнем углу -> New repository
2. Repository name: domashka
3. Выберите Public
4. Галочки "Add a README file" НЕ ставьте — README уже в папке
5. Кнопка Create repository


ШАГ 3. Загрузить файлы
----------------------
1. На странице пустого репозитория нажмите ссылку
   "uploading an existing file"
   (или: Add file -> Upload files)
2. Откройте эту папку и выделите ВСЁ содержимое: Ctrl+A
3. Перетащите выделенное в окно браузера
4. Внизу кнопка Commit changes

Файл ПРОЧТИ-МЕНЯ.txt можно не загружать — он только для вас.


ШАГ 4. Включить Pages
---------------------
1. Вкладка Settings (сверху справа)
2. В левом меню — Pages
3. Source: Deploy from a branch
4. Branch: main, папка: / (root)
5. Save

Подождите 1-2 минуты и обновите страницу Settings -> Pages.
Сверху появится адрес вида:

    https://ВАШ-ЛОГИН.github.io/domashka/

Это и есть ссылка. Работает на компьютере, планшете и телефоне.


ШАГ 5. Положить под руку
------------------------
Компьютер:  открыть ссылку -> Ctrl+D -> в закладки.

MatePad / телефон:
  1. Открыть ссылку в браузере
  2. Меню браузера (три точки) -> "Добавить на главный экран"
  3. На рабочем столе появится иконка, страница будет
     открываться как обычное приложение, без адресной строки


КАК ОБНОВЛЯТЬ ПОТОМ
-------------------
Когда появится новый разбор, вы получите свежий index.html.
Дальше:
  1. Открыть репозиторий на github.com
  2. Add file -> Upload files
  3. Перетащить новый index.html (он заменит старый)
  4. Commit changes

Через минуту страница обновится на всех устройствах сама.


ЧТО ВАЖНО ЗНАТЬ
---------------
1. Бесплатные GitHub Pages работают только с ПУБЛИЧНЫМ репозиторием.
   Страница доступна любому, у кого есть ссылка. В файле нет
   персональных данных — только разборы школьных тем. Имя, фамилию,
   оценки и расписание туда добавлять не нужно.

2. Отметки и результаты хранятся в браузере устройства. Чтобы
   не потерять их и перенести на планшет, откройте вкладку
   "Прогресс" (режим Штурман) -> "Сохранить в файл".
   На планшете: "Прогресс" -> "Загрузить из файла".
   Делайте это раз в неделю — файл лежит в папке проекта.

3. От поисковиков страница закрыта служебной строкой в коде,
   поэтому в Яндексе и Google она не всплывёт.


ЕСЛИ НЕ ХОЧЕТСЯ ЗАВОДИТЬ GITHUB
-------------------------------
Откройте app.netlify.com/drop и перетащите туда всю эту папку.
Через 10 секунд получите готовую ссылку — без регистрации.
Минус: адрес будет длинный и случайный, а обновить страницу
без аккаунта потом не получится.
